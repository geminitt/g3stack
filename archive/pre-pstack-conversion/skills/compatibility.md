# g3stack skill execution boundaries

Apply host/project instructions and the owner's existing personal agreements.
Resolve resources from the selected skill's real directory. This library is a
complete-checkout bundle: copying one folder does not supply its shared resources.

## Project work and standalone tasks

When selected within an active delegated project goal, a g3-* skill supplies
its bounded result and evidence to the ongoing coordination. Continue with the
next authorized activity after reassessing the goal; do not end the project or
ask the owner which skill to choose just because a procedure finished.
When the current request is a standalone bounded task, complete that task and
report its result. The owner's current pause, scope and stop decisions govern.
This shared contract does not create another project controller or ledger.

## Host and source mappings

Use the active host's actual tools and configured model. No vendor model alias,
slash command, agent type, background service or companion plugin is assumed.
Delegate only when supported, useful and authorized; otherwise work sequentially
and label self-review. Preserve independent confirmation where the selected audit
requires it; absent reviewers leave that audit incomplete.

Use the existing project record, accepted decisions and harness. Plan/commit/PR,
worktree, cleanup, installation, provider and publishing steps in source material
do not grant authority or require a second ledger. Reuse prior approval within its
scope. An external orchestrator stays a bounded, explicitly chosen subworkflow.

Meaningful fail-before/pass-after checking is conditional on a practical test path.
The selected g3stack procedure replaces raw always-TDD, mandatory fan-out, repeated
fresh-run and fixed-count rules. Keep valid unchanged evidence with source and
environment identity. Preserve required public compatibility and owner work.

Before executing a retained vendor helper or relying on vendor reference material,
run [the source check](../kits/engineering/check.py) once for the current unchanged
snapshot; it validates [the pinned manifest](../vendor/source-manifest.json).
Inspect the helper and its actual runtime/dependencies. A failed required source
check blocks that source-dependent action, not feasible independent project work.
Use python3 -B for Python helpers and keep generated output outside vendor.

Detailed source text is selected reference material, not a requirement to load
all related workflows. This library's scope and personal agreements bound its
use. Report only observed installation, discovery, loading, invocation and results.
